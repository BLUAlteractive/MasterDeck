# B026 — Evolved diagnostic fairness simulation

Added a test/development-only seeded six-cohort simulator, CLI, committed 100,000-hand aggregate evidence and CI reproduction. It compares Classic and Evolved on identical canonical deals, records win/tie/reversal/category/bonus distributions, tests neutral and purchased-skin counterfactuals and never enables live play. Hypothetical earned progression profiles are explicitly not real inventory/economy forecasts.

Changed files: game-poker `test/fairness.ts` and `src/fairness.test.ts`; `scripts/evolved-simulation.mts`; package script; CI workflow; `docs/simulations/evolved-a-v1.json`, balance report, decisions, status, this report and the final batch report. No runtime export, dependency, database migration, account mutation or economy parameter change.

`pnpm test:poker:evolved --output docs/simulations/evolved-a-v1.json` completed 100,000 hands with seed 230026: zero neutral mismatches, cosmetic payload changes, noninteger scores, duplicate decks or two-category upsets. Maximum earned versus baseline yielded **80.92% half-tie showdown share**, **+30.59 percentage points versus Classic on the same deals**. Early earned yielded **67.36%**, +18.17 points. These substantial advantages require review; CI success is not balance approval. Complete profiles, distributions, statistical limits, [NIST Wilson reference](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm) and reproduction are in [the balance report](EVOLVED_BALANCE_REPORT.md).

Focused tests passed deterministic repeat/seed variation, every cohort's conservation, controls and Wilson edge/numeric checks. Initial sandboxed CLI failed to create tsx's local IPC pipe; authorized rerun completed without network or database access. Final full quality and evidence-verification results follow below.
