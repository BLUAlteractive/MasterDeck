# B030 — Accessible Spades table

Added the reusable mobile Spades table, refresh-aware socket subscription, strict HTTP command/read methods and a versioned pending-command replica. B031 will mount it in private-lobby navigation. The table shows fixed partners, bids/nil, target/rules, scores/bags, current cards, exact last-trick winner, prior round deltas and match winner. Legal cards have explicit text and enabled controls; other cards are disabled. Disconnect pauses commands. Bids require confirmation; nil is explicit.

Changed files: mobile SpadesTable/semantic tests, spades-replica, spades-watch; collection client and shared Action surface contrast; mobile package/lockfile declares already-pinned socket.io-client 4.8.4; Spades contracts additionally reject multiple recipient hands and mismatched rules; decisions/status/report. No new version or persisted feature. The table consumes server projections and never computes wins or scores.

Subscriptions refresh authentication on reconnect with capped backoff, resume through the common protocol and abort late socket creation after unmount. Pending command IDs survive snapshot/reconnect updates; older receipts clear the matching pending command without rolling a newer snapshot back. Ambiguous transport failures keep the same request for retry. Definitive validation/stale rejections refresh authoritative state. Session/room component boundaries and cancellation prevent stale data crossing views. No token appears in query strings or logs.
