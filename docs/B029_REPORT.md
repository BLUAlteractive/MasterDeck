# B029 — Spades realtime actor

Added durable four-seat Spades rooms behind the existing authenticated `/rooms` socket and `/v1/games` HTTP protocol. The router selects the room's server-owned kind; BID/PLAY/CONTINUE are strict declarative commands. User/session/room locks serialize writers, immutable private events reconstruct each state, original receipts protect retries, and stale requests return recipient-safe snapshots. Only the server shuffles new rounds. No client deck, score, identity or outcome is accepted.

Changed files: game-spades projection/tests and index; Spades wire contracts/index; API Spades service/common router, app/socket/controller/shared conflict handling and four integration cases; Prisma room/seat/event/result models, `202610300005_spades_rooms` migration and matching owned rollback; API workspace dependency/lockfile; decisions/status and this report.

Projections expose only the recipient's remaining hand, public bids/tricks, legal options on their turn, fixed partners and team scores. The shared PostgreSQL notification carries only room UUIDs after commit; every cross-server delivery reauthenticates and projects afresh. Restart/reconnect replays private evidence. Terminal results are immutable team points, not Play Chip rewards or currency settlement. CONTINUE requests a server-generated next round only from ROUND_COMPLETE; its idempotency preserves scores and prevents redeal on retry. No timeout bot or guessed launch policy is introduced; disconnected games pause until resumed.

Rules are explicit and frozen per room. B029 supplies a server-only initializer; public eligibility/reservations/private admission belong to B031. Standard scoring values in tests are labeled fixtures, including a one-point target to exercise a complete match in one deal. Product policy approval remains separate.
