# B041 — Purchase restore and refund recovery

Implemented owner-scoped restore/current purchase history, durable periodic purchase rechecks, authenticated Google void pagination and immutable revocation tombstones. Restoring an existing canonical purchase never duplicates grants; refunds remove only benefits derived from that purchase, preserving an independent active purchase of the same cosmetic. Proofs/cursors remain encrypted; history never exposes them. A persisted void survives a crash before entitlement reconciliation, and old active receipts cannot reactivate it. No wallets, functional cards or earned progression are mutated.
