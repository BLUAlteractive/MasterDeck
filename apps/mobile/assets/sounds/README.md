# Original tap feedback

`tap.wav` is an original procedural 660 Hz sine tone, 80 ms, 22,050 Hz mono PCM16, amplitude 1,400 with a squared-sine envelope. It was generated locally from mathematics with Python's wave/struct/math libraries; no recording, music sample, brand sound or external asset was used. Playback is additionally limited to 15% volume, explicitly opt-in and foreground only. It never signifies a verified result on its own. Project source contributors retain the same project-source rights; commercial product/name review remains separate.
